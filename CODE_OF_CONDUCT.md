# Contributor Code of Conduct

## Our standard

We want D20 Dungeon Studio to be a constructive, technical, and welcoming project. Participants should communicate professionally and respectfully, especially when discussing architecture, game design, code quality, or competing approaches.

## Expected behavior

- Be respectful and assume good faith.
- Give actionable technical feedback.
- Credit other contributors and external references appropriately.
- Keep criticism focused on the work rather than people.
- Respect project licensing and intellectual-property boundaries.

## Unacceptable behavior

Harassment, threats, discrimination, personal attacks, deliberate disruption, credential exposure, malicious code submissions, and knowingly violating project or third-party licenses are not acceptable.

## Enforcement

Project maintainers may edit, close, reject, or remove contributions that violate this code or applicable project policies. Serious or repeated violations may result in loss of contribution privileges.

For security-sensitive matters, use private reporting rather than public issue discussion.
