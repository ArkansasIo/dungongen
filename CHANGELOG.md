# Changelog

All notable releases of D20 Dungeon Studio are documented here.

## Development credits

D20 Dungeon Studio is developed and packaged under the **Endgame Studio** development-studio identity, with **ArkansasIo** as the GitHub developer/account identity.

## [Unreleased]

Current development work is tracked on `main`.

## Release channels

- **Alpha** — internal/early feature validation; APIs and gameplay systems may change.
- **Beta** — feature-complete validation; focus shifts to stability, compatibility, balancing, and release testing.
- **Release Candidate (RC)** — production candidate; only release-blocking fixes should be accepted.
- **Gold** — final release build intended for general distribution.

## Versioning

D20 Dungeon Studio uses Semantic Versioning (`MAJOR.MINOR.PATCH`) with pre-release identifiers where appropriate, for example `1.0.0-alpha.1`, `1.0.0-beta.1`, `1.0.0-rc.1`, and `1.0.0` for Gold.
